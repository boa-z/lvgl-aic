# GE2D linear FILL stage

The application-owned GE2D fill executor now accepts the bounded gradient
subset that the ArtInChip GE API can represent directly: two stops at fractions
0 and 255, opaque stops, `LV_GRAD_EXTEND_PAD`, and horizontal or vertical
direction. Both perpendicular and along-axis clips are accepted: the two GE
endpoints are sampled with LVGL's own stop calculator so the ramp keeps its
full-task coordinate.

Solid fills retain their existing path. Rounded rectangles, arbitrary linear
gradients, radial/conical gradients, repeated/reflected extension, more than
two stops and translucent stops continue through LVGL software rendering.
Partial descriptor opacity remains supported for RGB destinations; straight
ARGB targets use the existing bounded staging/native blend tail. Tasks longer
than the bounded 256-pixel gradient axis still use software. The SDK CMDQ
gradient correction is still generated by the application integration tool and
checked against its reviewed SDK source hash.

## Host contract

`lvgl_aic_ge2d_fill_contract` covers both horizontal and vertical descriptors,
full-area endpoint colors, GE gradient type selection, and rejection of a
complex linear descriptor. The complete GE host suite and SDK GE2D integration
must pass before this stage is considered complete.

The contract does not establish physical gradient pixels, CMDQ cache behavior,
or panel output. Board execution remains **NOT_RUN** until the next unified
D50T validation session.
